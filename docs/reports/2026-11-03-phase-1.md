## What changed
- `src/app.js`: the `webglcontextlost` handler sets `gpuLost`; `initGpu()` skips `dispose()` of the simulation, renderer and
  frame fence while it is set (those objects died with the context), then clears it. The wrong "harmless no-ops" comment is
  replaced. `src/gl/context.js` (the format probe) is unchanged, so first-start probing is unchanged by construction.
- `tests/browser/ui-flow.js`: a regression block. It loads the page, requires float32 at start (otherwise it logs "not
  applicable"), pauses, loses and restores the context, and asserts: same format after the restore; the re-seeded state reads
  back with error 0 at generation 0; the Observatory resumes; no GL error. The comment on the older O2b restore check is updated.
- `src/ui/controls.js`: the colour map's display label "Observatory" becomes "Ocean" (owner decision D8); the internal id
  `observatory` is unchanged.
- Documentation: `.claude/skills/lenia-validation/SKILL.md` (per-pattern parity horizon and the float16 tolerance, matching
  `DECISIONS.md` 12 and 23); `progress.md` (Phase 2 row, Phase 4 row label, new fact 22, the float16 item resolved and the older
  "Context restore" item merged into fact 22, tour-testing wording, planned item 1); `DECISIONS.md` 3, 20 and 21; `README.md`
  (palette label); `docs/reports/2026-11-03-phase-0.md` (owner decision D9) and this report.
