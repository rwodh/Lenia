## Deviations
- **Test-page CSP.** The handoff asked for a CSP header equal to the meta CSP. The app gets exactly that (plus
  `frame-ancestors`). The test pages, which had no CSP before, get the same policy plus `frame-src 'self'`, because
  `ui-flow.html` must frame `index.html`. No policy was loosened for the app.
- **Inline styles moved** out of the three test pages (no visual or behavioural change intended).
- **Three existing ui-flow checks changed** to be deterministic under GPU pressure, all stricter than before:
  (a) the back-off check held `gpuBound` by setting `cleanFrames = -1e9`, but `App.frame()` resets `cleanFrames` to 0 on any
  frame the fence holds back, after which the loop recovers in 60 frames; the check now pins `gpuBound` with a property
  override. (b) "sampling resumes after Reset" and (c) "after switching to O2b" expected a sample before generation 60, which
  no sample can meet while the GPU is behind (by design no samples are taken then); they now pause first and require the first
  sample to be generation 0 with the seed's exact mass. The Phase 1 restore regression got the same treatment (paused, generation
  0, exact seed mass).
